# Placenta Genomics Database
This repository contains data and code for annotating placenta genomics datasets.

Our aim here is to: 
  1. Develop a resource for the placenta community for identifying placenta -omics samples
  2. Assess the history and current state of placenta -omics research

Here we provide: 
  1. Code to generate the initial pull of placenta -omics data drawn from the gene expression omnibus (GEO) repository
  2. Code to extract the metadata from the publicly available GEO repository entries
  3. Code to use AI to extract additional metadata from the publications associated with the GEO entries
  4. Code to analyze the full set of metadata associated with the placenta -omics related entries
